# Getting help

- **Questions and ideas**: open a thread in
  [GitHub Discussions](https://github.com/coreplanelabs/switchboard/discussions).
- **Bugs**: open an issue with the bug template. Include the version or commit,
  your `config.yaml` with secrets removed, and the run's events if you have them
  (`runs events <id>` on the CLI, or the run page).
- **Security problems**: never in a public issue. See [SECURITY.md](SECURITY.md).
- **Documentation**: the [`docs/`](docs/README.md) tree is organized as
  tutorials, how-to guides, reference, and explanation. Start there before
  asking; if the answer should have been there and was not, that is a docs bug
  worth an issue.

Maintainers respond on a best-effort basis. There is no commercial support.
