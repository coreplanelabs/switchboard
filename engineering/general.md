## General coding

- Preserve the requested outcome, settled behavior and permission limits. Read the repository's relevant rules and nearby code before choosing a pattern. Repository guidance supplies concrete types, APIs and boundaries. State and resolve a conflict; do not silently drop a contract.
- Use idiomatic language features, types, naming and resource management. Reuse established patterns that meet these rules. Make the smallest clear change that solves the task; avoid speculative frameworks and unrelated cleanup.
- Skills supply task methods under these shared rules. Keep policy in its owning rule file, not repeated in skills or task prompts. Explain non-obvious choices where the repository records decisions.
