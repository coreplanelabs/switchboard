# Tutorials

**"Walk me through it."** A tutorial takes you from nothing to one working result along a path known to work. It makes the decisions for you. If you already know what you want, you want a [how-to guide](../how-to/).

- [Get started](get-started.md): what Switchboard is, an answer in your terminal, then a bot in your Slack — ten minutes, one process.
- [Your first request in Slack](first-request-in-slack.md): send a request, follow up in the thread, hand a task to a specialist agent.
- [Run it locally](run-it-locally.md): the contributor's loop, from a checkout of the repository.
