# Tutorials

**"Walk me through it."** A tutorial is a lesson: it takes a stated reader from nothing to one working result along a path that is known to work. It makes the decisions for you — no options, no alternatives, no "it depends" — so the only thing you have to do is follow along and see it work.

If you already know what you want and need the steps for *your* situation, you want a [how-to guide](../how-to/) instead.

- [Get started](get-started.md) — from nothing to a running `ask`, then Slack, then production, one command each.
- [Your first request in Slack](first-request-in-slack.md) — send a request, follow up in the thread, hand a task to a specialist agent and watch its run.
- [Run it locally](run-it-locally.md) — an answer from OpenSwitchboard on your own machine, and the run it recorded, with no Slack workspace.
