# Main agent actions on linked work

For status, steer, and stop, the main agent addresses one existing Ship unit by the durable `(main thread, act id)` link. The requester's resolved identity and current thread are trusted context; model text cannot pick another task or requester. Those linked-work actions do not start a worker or expose its private brief; typed start is a separate path.
