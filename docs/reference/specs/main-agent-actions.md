# Main agent actions on linked work

The main agent addresses one existing Ship unit by the durable `(main thread, act id)` link. The requester's resolved identity and current thread are trusted context; model text cannot pick another task or requester. This service does not start a worker or expose its private brief.

- **Code**: `src/core/coordinator/mainActions.ts`, `src/core/coordinator/instanceStore.ts`, `src/core/coordinator/contract.ts`, `src/core/planeService.ts`, `src/core/authz/policy.ts`, `deploy/cloudflare-memory/worker.ts`
- **Tests**: `src/core/coordinator/mainActions.test.ts`, `src/core/authz/policy.test.ts`, `deploy/cloudflare-memory/runLedger.test.ts`

| Criterion | Proof |
|---|---|
| Status reads the exact linked unit and its unchanged claimed branch for the requester in the current main thread. It returns a small status, branch and pull request projection without the brief, private thread, run ids, or report. Missing, stale, foreign and cross-thread links reveal no task facts. | `[unit]` `src/core/coordinator/mainActions.test.ts::main task actions::status projects only the requester's linked unit without private context`; `::a foreign or cross-thread caller cannot read the link`; `::a changed unit branch revokes status, steer, and stop for the claimed task` |
| Steering writes a bounded event under a stable action id to that unit and nudges its Workflow. An orchestrator acting for the bound requester writes the requester's sender id so an idle unit recognizes the wake. Repeating the same action appends no second event; reusing its id with different words refuses. A failed nudge leaves the event queued for the coordinator's next read. A stopped, ended, recovered, or mismatched unit receives no event; the durable append rechecks the exact claimed task and active state atomically with the event write, including a racing stop or branch change, and returns the stored event for bounded replay verification. A later whole-row update cannot rewrite a claimed brief. | `[unit]` `src/core/coordinator/mainActions.test.ts::main task actions::steer persists one event and a replay cannot change its words`; `::a main-agent steer wakes as the bound requester`; `::a failed nudge leaves the event queued`; `::terminal units refuse a steer and a later brief rewrite cannot change the binding`; `::a mismatched stored brief refuses a steer before writing an event`; `::a stop racing the append leaves no steer on a terminal unit`; `::a branch change racing the append leaves no steer on the former claimed unit`; `::a persisted steer is nudged without reading the unit's full event history`; `[worker]` `deploy/cloudflare-memory/runLedger.test.ts::run ledger — the coordinator's unit events (record 0051's reply-as-event rule)::guards a main-task steer against a stop in the same append transaction`; `::atomically refuses main-task steer and stop after the claimed branch changes` |
| A requester can stop their own linked work without an operator grant. The narrow policy row checks self identity, and the stop mark atomically rechecks the claimed task before ending any run. Its answer reports a partial stop when the runner mark or any required run stop failed. A stop targets only child runs tagged with that instance, even when unrelated runs share a unit thread. A foreign, view-as or non-person caller changes nothing. | `[unit]` `src/core/coordinator/mainActions.test.ts::main task actions::stop preserves exact ownership and reports the plane outcome`; `::a branch change racing the stop leaves the former claimed instance running`; `::a failed child stop reports partial even when the runner mark succeeded`; `src/core/authz/policy.test.ts::main task stop authorization::admits only the requester without an operator grant`; `src/core/planeService.test.ts::plane stop — the runner_stop move (record 0064; issue 1924)::terminates the instance and ends its live children in one move: the stop mark first, the hosted parent hard-stopped, then every live child in a unit thread — never the parent twice` |
| The main agent can start and bind a private worker and deliver a steer to a currently running coding child. | `[gap]` Typed tool registration, private child live delivery, and main-thread progress relay are integration work; this service queues input for the existing coordinator fold. |
