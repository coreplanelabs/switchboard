- **Boundary**: An operator previews and applies a reset to one explicit account. Reset removes application state, preserves settings and access, and does not establish the original outcomes of discarded work. Staging acceptance and any production execution are separate.

The [operator procedure](../../how-to/reset-installation.md) defines the profile, original secret source, maintenance episode, plan and private execution receipt. Preview is read-only. A serialized apply requires the exact account and plan; missing restoration input or active work refuses before deletion. A failure keeps the original operation and maintenance hold.
