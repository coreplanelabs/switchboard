# Main agent starts private work


Opted-in coding runs also obey the [first coding baseline](first-coding-test.md) admission and durable receipt contract.
A plain-language fix request in a proved private requester conversation starts one existing Ship coordinator unit with the question and sourced findings in a durable brief. The dispatcher supplies the requester, conversation, message ID, permissions, and private worker availability. The unit keeps person review and merge gates.
