# Saved context for the operator

The operator uses durable working notes and cross-session memory through the same storage seams as execution. Context is advisory; stored text supplies no authority.

## Behavior

1. Notes reads start from run identities already admitted by the caller's run-read capability. Each run must match the current thread and destination. Another requester's notes require the canonical producer origin and a current source visibility check; public origin access uses the current reader without rewriting the original producer. Its persisted session key is canonical, including a unit lane; an absent identity does not invent an agent session. Each distinct session is read once.
2. The notepad is read independently of transcript compaction. The full typed dependency envelope is checked after reading the note snapshot, so a concurrent source dependency cannot be omitted from its checks. Unknown, revoked or unsupported full source provenance omits that note with an explicit unavailable reason. The independent legacy Slack tracker does not veto a known full envelope. A known typed dependency envelope passes the current source revalidator before the operator receives text; legacy metadata alone cannot establish source-free notes. A private destination also passes the existing private-audience check. No transcript prose or tool name establishes source authority.
3. Memory retrieval admits only the request's allowed scopes and records whose exact frozen content revision and bounded context dependencies pass a current source-owner read capability. Its immutable content digest must match before that capability is called; source run identity alone cannot establish that inherited inputs remain readable. Both keyword retrieval and repository-window listing filter before context rendering. Missing legacy dependencies, modified content, denied or unavailable source checks, scope mismatches and failed store reads omit the affected records while preserving independently authorized context. Every admitted memory scope is also retained as an access dependency, so transformation or a public producer cannot widen a private user memory's audience. The read returns the admitted dependency union beside the rendered block, so downstream producers preserve the same envelope. Empty reads may return known-empty dependencies because no source bytes were consumed. Memory remains disabled when its existing config is off.
4. Notes, memory and conversation tails return the dependency closure of every admitted byte beside their content. The operator records the union before asking the model. Shared conversation rows carry explicit individual envelopes; a missing or denied row is omitted without discarding other proved rows. Legacy working logs require a known complete envelope checked after the byte snapshot. Thread history uses the shared session first, with canonical authorized run sessions supplying bounded migration context when the new log is empty or contains only this admitted request.
5. The message-bound context reader checks original run identities and current requester grants. Completed runs use their retained dependency and source-action archives, never a later shared session. Stored actions are freshly inspected with their original owner, session and query; consuming saved context does not execute them again. Memory must preserve its canonical producer's dependencies. Repository metadata and README content preserve the original exposed repository names as one bounded catalog-access leaf. Reuse checks each original name is still in the current public requester-authorized catalog; README edits do not invalidate an earlier content snapshot. Catalog overflow is named and never silently drops dependencies. Artifact recovery pages through the greatest frozen source cursor and excludes later events.

6. Publication revalidates the actual admitted input envelope (the seed plus new context admissions) alongside existing live source checks. It validates a frozen snapshot and retries once if admission changed during the asynchronous check; continued change, unknown or missing proof, denied access and unavailable validation withhold publication. Cumulative retained/export context remains separate: omitted legacy rows or fresh opaque results can leave it unknown and unavailable for reuse without blocking a fresh answer whose admitted inputs and live source checks pass. No omission clears retained dependencies.
7. A committed coordinator delivery can add a separate typed status observation to the shared conversation. It includes the work identity, allowlisted result, attempt, canonical delivery or recovery label, and a PR pointer only when bound to a terminal outcome. It excludes report, title, reason and error prose. Its dependency points to the exact immutable stored observation; a newer unit status cannot replace it. Reuse requires the current canonical unit owner, repository and audience, including a private worker's original main-task link. Missing legacy proof skips this optional observation without blocking the existing raw delivery. Raw reports keep unknown provenance. The main agent can use an admitted work identity to request current details.
8. A committed ordinary-session checkpoint can replace equivalent run-origin identities before a long history or note closure reaches its bound. The reader verifies the exact retained seed, canonical membership and current origin audience. It preserves each admitted item's external dependencies; later unrelated sources are not imported into an earlier row. Prepared, missing or changed checkpoints confer no access. Notes normalize individual canonical origins before union; shared history checks individual rows before normalization.
9. The operator revalidates its exact admitted inputs before publishing or persisting model text and before applying a decision. A revoked or unavailable source withholds the decision without persisting its text or starting its effects. Pending questions and proposals retain that same input envelope on their canonical record; a later answer reads and validates that record before joining its text or binding a bare assent. Missing legacy proof makes the pending decision unavailable.
