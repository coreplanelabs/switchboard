# Cold branch publication

A coding child of Ship can begin on a branch that the coordinator already created. The runner binds publication to that branch's fetched head before model work, advances the lease only from a durable accepted write, and keeps an uncertain effect unresolved.

- **Code**: `src/execution/factory.ts`, `src/core/dispatcher.ts`, `src/core/dispatch/runLoop.ts`, `src/core/publicationEffect.ts`, `src/core/codingPrPostStep.ts`
- **Tests**: `src/execution/factory.test.ts`, `src/core/dispatcher.test.ts`, `src/core/dispatch/runLoop.test.ts`, `src/core/publicationEffect.test.ts`, `src/core/codingPrPostStep.test.ts`, `src/core/publicationSettlement.test.ts`, `src/channels/githubDoorIntegration.test.ts`
