The replacement dashboard uses the current execution engine through HomeSession. Home shows assigned questions and work context; one composer sends to the explicitly selected destination. [Record 0102](../../decisions/0102-the-browser-cutover-keeps-the-current-execution-engine.md) replaces the old rail and pinned Plane composer. Native adapter APIs remain compatible; their tests do not prove production activation of the new browser host.

## Behavior

1. Home uses one private broad session and one explicit-destination composer. Reading a thread does not select it for a reply. A fresh server proof is required before Reply changes the destination.
2. Recorded run turns retain their request, receipt, answer, facts, and shared replay fold. A failed run without a reply shows its recorded outcome. Silent receipts and the parent's recorded words stay in transcript order; neither creates a model run.
3. Current source or identity loss clears private transcript, drafts, and pending retries. View as remains read-only. Unknown submission outcomes retain the issued key and immutable payload; a retry checks that saved submission.
4. The removed conversation rail, local owner toggles, brand motion, and pinned Plane chat are superseded. Their backend run, thread, and saved-choice APIs remain available to native clients.
